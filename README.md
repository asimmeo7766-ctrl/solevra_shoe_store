# Solevra Traditional Footwear Website

A responsive front-end e-commerce starter website using the original product photographs supplied in the conversation.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For best results, run a local static server from this folder, for example: `python -m http.server 8000`, then visit `http://localhost:8000`.

## Included
- Modern responsive storefront with dark brown, cream and gold styling.
- Original uploaded product photos copied into `assets/images/` (no replacement stock photos).
- Red Peshawari: PKR 3,399.
- Maroon Peshawari: PKR 3,399.

- Cart, quantity controls and checkout order-request flow.
- Login and registration demo.
- Contact number and WhatsApp link: +92 322 9292184.

## Important production notes
This ZIP is a front-end starter/demo. Browser `localStorage` is used for demonstration only. It is not a secure multi-customer database and does not provide real authentication, central stock control, order notifications, or payment processing.

Before accepting real orders:
- Connect a backend and database (for example Supabase/PostgreSQL).
- Implement secure server-side authentication and password hashing.
- Add admin-only product, price and stock management.
- Integrate a supported payment gateway and verify payment callbacks server-side.
- Configure shipping charges, returns policy, privacy policy and production hosting.
- Confirm product image-to-colour mapping and replace any incorrectly assigned gallery image if needed.
